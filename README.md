## 🚀 Быстрый старт (HTTP API режим - рекомендуется)

### 1. Установка зависимостей

```powershell
# Python зависимости
pip install -r requirements.txt

# Node.js зависимости
cd nodejs
npm install
cd ..
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=your_telegram_bot_token_here
SPARK_API_PORT=3000  # Порт для API сервера (опционально)
```

### 3. Запуск API сервера (в отдельном терминале)

```powershell
.\start_api_server.ps1
```

Должно появиться:
```
============================================================
🚀 Spark SDK API Server запущен!
📡 Listening on: http://127.0.0.1:3000
⚡ Готов к обработке 1000+ одновременных запросов
============================================================
```

### 4. Запуск бота (в другом терминале)

**PowerShell:**
```powershell
.\start_bot.ps1
```

**CMD:**
```cmd
start_bot.bat
```

**Напрямую:**
```powershell
python telegram_bot.py
```

### 5. Тестирование HTTP API

```powershell
python test_http_api.py
```
