# 🚀 Быстрый старт: HTTP API режим

## Что изменилось?

Бот теперь работает через **HTTP API сервер** вместо subprocess.
Это позволяет обслуживать **1000+ пользователей одновременно**.

## 📋 Шаги для запуска

### 1. Установить Express.js (один раз)

```powershell
cd nodejs
npm install
cd ..
```

### 2. Запустить API сервер (в отдельном терминале)

```powershell
.\start_api_server.ps1
```

Должно появиться:
```
============================================================
🚀 Spark SDK API Server запущен!
📡 Listening on: http://127.0.0.1:3000
⚡ Готов к обработке 1000+ одновременных запросов
============================================================
```

### 3. Запустить бота (в другом терминале)

```powershell
.\start_bot.ps1
```

## ✅ Проверка

Откройте браузер: http://127.0.0.1:3000/health

Должно быть:
```json
{
  "status": "ok",
  "timestamp": "2024-01-20T10:30:00.000Z",
  "uptime": 123.45
}
```

## ⚠️ Важно

**API сервер должен быть запущен перед ботом!**

Если бот показывает ошибку:
```
❌ API сервер не запущен. Запустите: cd nodejs && npm start
```

Значит вы забыли запустить API сервер (шаг 2).

## 🔄 Автозапуск (опционально)

Для продакшена используйте PM2:

```powershell
npm install -g pm2
cd nodejs
pm2 start api_server.js --name spark-api
pm2 startup
pm2 save
```

Теперь API сервер будет запускаться автоматически при старте системы.
