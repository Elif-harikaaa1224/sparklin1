# 🛒 buy_handlers_extended.py - Расширенные обработчики покупки

## 📋 Описание

Этот модуль содержит дополнительные обработчики для процесса покупки токенов:
- Настройка slippage (проскальзывания цены)
- Ввод custom значений (tip, slippage)
- Подтверждение покупки
- Выполнение покупки
- Отмена покупки

## 🔧 Основные функции

### 1. `handle_buy_set_slippage()`
**Назначение**: Открывает меню настройки slippage

**Особенности**:
- Показывает клавиатуру с предустановленными значениями (5%, 10%, 15%, 20%)
- Позволяет ввести custom значение
- Объясняет что такое slippage

### 2. `handle_slippage_selection()`
**Назначение**: Обрабатывает выбор slippage из меню

**Параметры**:
- `callback.data`: "slippage_10.0", "slippage_custom", "slippage_back"

**Действия**:
- Обновляет slippage в state
- Возвращается к главному меню покупки
- Показывает обновленную информацию

### 3. `handle_custom_tip_input()`
**Назначение**: Обрабатывает ввод custom buy tip

**Валидация**:
- Минимум: 100 sats (0.000001 BTC)
- Максимум: 0.01 BTC
- Проверка формата числа

**Примеры ввода**:
```
0.000001  # 1000 sats
0.00001   # 10000 sats
1000      # 1000 sats (автоконвертация)
```

### 4. `handle_custom_slippage_input()`
**Назначение**: Обрабатывает ввод custom slippage

**Валидация**:
- Минимум: 0.1%
- Максимум: 50%
- Проверка формата числа

**Примеры ввода**:
```
10     # 10%
15.5   # 15.5%
20     # 20%
```

### 5. `handle_buy_confirm()`
**Назначение**: Показывает подтверждение покупки

**Отображает**:
- Детали токена (символ, имя, адрес)
- Сумму покупки в BTC и USD
- Выбранный кошелек
- Buy tip
- Slippage
- Предупреждения и риски

**Кнопки**:
- ✅ Подтвердить покупку
- ❌ Отменить

### 6. `handle_buy_execute()`
**Назначение**: Выполняет покупку токена

**Процесс**:
1. Получает параметры из state
2. Показывает индикатор загрузки
3. Вызывает API покупки (через UTXO Pool / Flashnet)
4. Обрабатывает результат
5. Показывает статус (успех/ошибка)
6. Добавляет позицию в портфель

**Параметры покупки**:
```python
{
    "token_address": "btkn1...",
    "amount_btc": 0.001,
    "wallet_address": "spark1...",
    "buy_tip": 0.0000001,
    "slippage": 10.0
}
```

### 7. `handle_buy_cancel()`
**Назначение**: Отменяет покупку и возвращает в главное меню

**Действия**:
- Очищает state
- Показывает сообщение об отмене
- Возвращает в главное меню

### 8. `format_buy_message()`
**Назначение**: Форматирует сообщение с информацией о покупке

**Параметры**:
- `token_info` - информация о токене (символ, имя, цена, ликвидность)
- `wallet_balance` - баланс кошелька в BTC
- `selected_wallet` - выбранный кошелек (W1, W2, etc.)

**Возвращает**:
```
🛒 Buy $MIM — Magic Internet Money 📈

📍 btkn1fa6l5xk...snkh0dl

💰 Balance: 0.00008800 BTC — W1
💵 Price: $0.00007333
💧 LIQ: $12.34K — 📊 MC: $73.33K

👇 Select options below:
```

## 📊 Flow покупки

```
1. Пользователь вводит адрес токена
   ↓
2. buy_handlers.py - получает информацию о токене
   ↓
3. Пользователь выбирает параметры (wallet, amount, tip, slippage)
   ↓
4. buy_handlers_extended.py - обработка custom значений
   ↓
5. handle_buy_confirm() - показывает подтверждение
   ↓
6. handle_buy_execute() - выполняет покупку
   ↓
7. Добавляет позицию в портфель
   ↓
8. Показывает результат
```

## ⚙️ Настройки и лимиты

### Buy Tip:
- **Минимум**: 100 sats (0.000001 BTC)
- **Максимум**: 0.01 BTC
- **По умолчанию**: 0.0000001 BTC (10 sats)

### Slippage:
- **Минимум**: 0.1%
- **Максимум**: 50%
- **По умолчанию**: 10%

### Amount:
- **Минимум**: 0.0001 BTC
- **Максимум**: Баланс кошелька
- **Быстрые варианты**: 0.001, 0.005, 0.01, 0.05 BTC

## 🎯 Примеры использования

### Изменение slippage:
```python
# Пользователь нажимает кнопку "Slippage"
# → handle_buy_set_slippage()
# → Показывается меню с вариантами
# → Пользователь выбирает 15%
# → handle_slippage_selection()
# → Обновляется state
# → Возврат к главному меню покупки
```

### Custom buy tip:
```python
# Пользователь нажимает "Custom" под Buy Tip
# → Переход в состояние waiting_buy_tip
# → Пользователь вводит "0.00001"
# → handle_custom_tip_input()
# → Валидация (0.000001 ≤ 0.00001 ≤ 0.01) ✓
# → Обновляется state
# → Возврат к главному меню покупки
```

### Подтверждение и выполнение:
```python
# Пользователь нажимает "✅ Купить"
# → handle_buy_confirm()
# → Показывает детали покупки
# → Пользователь нажимает "✅ Подтвердить"
# → handle_buy_execute()
# → Выполняется покупка
# → Добавляется позиция
# → Показывается результат
```

- Обработка некорректного ввода
