# ⚠️ ВАЖНО: Режим работы покупки токенов

## 🔧 Текущее состояние

### ✅ Что работает:
1. **Полный UI flow покупки** - все кнопки, меню, выбор параметров
2. **Получение данных токенов** - через UTXO.fun Pools API
3. **Расчет количества токенов** - на основе текущей цены
4. **Проверка баланса** - реальный баланс из UTXO.fun API
5. **Валидация параметров** - проверка сумм, slippage, tip

### ⚠️ Тестовый режим:
- **Транзакции НЕ отправляются в сеть**
- Генерируется тестовый TxID для демонстрации
- Токены НЕ зачисляются на кошелек

## 🛠️ Почему тестовый режим?

Мы удалили модуль `flashnet_integration` который содержал интеграцию с реальным API для покупки токенов. Сейчас используется метод `buy_meme_native()` который:

1. Создает корректную структуру транзакции
2. Рассчитывает ожидаемое количество токенов
3. Генерирует тестовый TxID
4. Возвращает все данные для UI

Но **не отправляет транзакцию в блокчейн**.

## 🔄 Как исправить?

### Вариант 1: Восстановить Flashnet Integration
```bash
# Скопировать из резервной копии bot999
Copy-Item "C:\spark-wallet-bot3\spark-wallet-bot999\flashnet_*.py" "C:\spark-wallet-bot3\"
```

Потребуется:
- `flashnet_integration.py`
- `flashnet_amm_client.py`
- `flashnet_auth.py`
- Настройка API ключей

### Вариант 2: Интеграция с Spark Node API
Требуется разработка:
1. Подключение к Spark Node
2. Создание реальных транзакций
3. Подпись приватным ключом
4. Отправка в сеть

### Вариант 3: Использовать существующий SDK
Если есть готовый Spark SDK для покупки токенов:
```python
from spark_sdk import buy_token

result = await buy_token(
    wallet_address=wallet_address,
    token_address=token_address,
    amount_sats=amount_sats,
    private_key=private_key
)
```

## ❓ FAQ

**Q: Почему была удалена Flashnet интеграция?**  
A: При очистке проекта были удалены неиспользуемые модули. Flashnet можно восстановить из резервной копии.

**Q: Можно ли использовать бота в продакшне?**  
A: Сейчас - только для демонстрации UI. Для реальных покупок нужна интеграция с API.

**Q: Что делать если нужны реальные транзакции?**  
A: Восстановить Flashnet модули или интегрировать другой API для покупки токенов.

**Q: Безопасно ли тестировать?**  
A: Да, тестовый режим не отправляет транзакции и не тратит средства.
